내 컴퓨터를 개발용으로 세팅하기

개발을 하려면 컴퓨터에 몇 가지 프로그램이 더 필요합니다. 여러 사이트를 돌아다니며 하나씩 찾지 않도록, 한 번에 설치해주는 스크립트를 만들었어요. 설치되는 것은 Claude 또는 ChatGPT 앱, 그리고 웹사이트나 프로그램을 만들 때 자주 쓰는 필수 프로그램들입니다.

스크립트는 두 개예요. 첫 번째는 프로그램을 설치하고, 두 번째는 GitHub, Vercel, Supabase에 로그인해서 매번 다시 로그인하지 않아도 되게 해줍니다.

걸리는 시간 20~30분 준비물 인터넷, 충전기, GitHub 계정(없으면 중간에 만들어요) Mac 로그인 비밀번호
  1. 1

    PowerShell 열기

    키보드의 ⊞ Windows 키를 누르고 powershell이라고 입력하세요. 맨 위에 나오는 Windows PowerShell을 클릭합니다.

    PowerShell은 뭔가요? 마우스 대신 글자로 컴퓨터에 일을 시키는 창입니다. 설치 프로그램 10개를 하나씩 내려받는 대신, 여기에 명령어 한 줄을 넣어 한 번에 설치할 거예요.

    "관리자로 실행"은 누르지 마세요. 그냥 클릭해서 여는 게 맞습니다. 관리자 권한이 없어도 설치되도록 만들어 두었어요.
  2. 2

    설치 명령어 붙여넣기

    아래 복사 버튼을 누르고, PowerShell 창을 클릭한 뒤 Ctrl + V(또는 마우스 우클릭)로 붙여넣고 Enter를 누르세요.

    irm https://raw.githubusercontent.com/whatfontisthis/claude-setup/main/install.ps1 | iex

    이 한 줄이 하는 일 irm은 인터넷에서 설치 스크립트를 받아오고, iex는 받은 스크립트를 실행합니다. 스크립트 내용은 누구나 GitHub에서 열어볼 수 있어요.

  3. 3

    쓸 AI 앱 고르기

    설치가 시작되자마자 한 번 물어봅니다. 숫자를 입력하고 Enter.

    • 1 Claude
    • 2 ChatGPT (Codex): Codex는 ChatGPT 앱 안에 들어 있어요
    • 3 둘 다: 수업에서 뭘 쓸지 모르겠으면 이걸 고르세요
  4. 4

    기다리기 (10분 정도)

    [1/10]부터 [10/10]까지 차례로 설치됩니다. 글자가 빠르게 지나가도 읽을 필요 없어요. 창을 닫지만 마세요.

    설치되는 것들을 쉽게 말하면 이렇습니다.

    Git
    코드를 저장할 때마다 기록을 남겨서, 망가지면 되돌릴 수 있게 해줍니다

    Python, uv
    Python 코드를 실행하고, 필요한 부품(패키지)을 깔아주는 도구
    GitHub CLI
    내 코드를 GitHub에 올리고 관리하는 도구
    Supabase CLI
    앱의 데이터베이스(회원, 게시글 등)를 관리하는 도구
    Vercel CLI
    만든 웹사이트를 인터넷에 공개(배포)하는 도구

    이걸 내가 직접 쓰나요? 거의 안 씁니다. AI 앱이 코드를 만들고 실행하고 배포할 때 이 도구들을 대신 씁니다. 우리는 AI에게 말로 시키면 돼요.

    노란 글씨나 빨간 글씨가 보여도 놀라지 마세요. 대부분 안내 메시지입니다. 정말 실패한 항목은 마지막에 따로 모아서 보여줍니다. "예"를 누르라는 팝업이 뜨면 "예"를 누르세요.
  5. 5

    결과 확인하기

    마지막에 설치된 목록이 나옵니다. 전부 ✓면 성공이에요.

    ✗나 "실패한 항목"이 보이면 같은 설치 명령어를 한 번 더 실행하세요. 이미 된 건 건너뛰고 실패한 것만 다시 시도합니다. 두 번 해도 안 되면 그 화면을 사진 찍어서 선생님께 보여주세요.

  6. 6

    로그인하기

    PowerShell 창을 닫고 새로 연 다음, 아래 명령어를 붙여넣고 Enter.

    irm https://raw.githubusercontent.com/whatfontisthis/claude-setup/main/login.ps1 | iex

    왜 창을 새로 여나요? 방금 설치한 도구들은 새로 연 창에서 확실하게 인식됩니다. 왜 로그인하나요? AI가 내 이름으로 GitHub에 코드를 올리고, Vercel에 배포하고, Supabase에 데이터베이스를 만들려면 내 계정에 연결돼 있어야 해요.

    GitHub → Vercel → Supabase 순서로 진행됩니다. 매번 브라우저가 열리고, 로그인한 뒤 터미널로 돌아오면 다음으로 넘어가요.

    GitHub질문에 엔터 → 8자리 코드 확인 → 엔터 → 브라우저에 코드 입력 → Authorize
    Vercel엔터 → 브라우저에서 로그인 → 코드가 같은지 확인하고 승인
    Supabase엔터 → 브라우저에서 로그인 → 나온 인증 코드를 복사해서 터미널에 붙여넣기
    Vercel, Supabase 계정이 없다면 로그인 화면에서 Continue with GitHub를 누르세요. GitHub 계정 하나로 가입이 끝나서 비밀번호를 따로 만들 필요가 없습니다.
  7. 7

    AI 앱 열고 첫 프로젝트 폴더 고르기

    시작 메뉴에서 Claude 또는 ChatGPT 앱을 열고 로그인하세요. 프로젝트 폴더를 고르라고 하면 C:\projects 안에 새 폴더(예: my-first-app)를 만들어서 선택합니다.

    왜 바탕화면이 아니라 C:\projects인가요? 바탕화면과 문서 폴더는 OneDrive가 동기화하는 경우가 많아요. Next.js 프로젝트에는 파일이 수만 개 생기는데, 이게 동기화되면서 설치가 깨지거나 아주 느려집니다. C:\projects는 동기화되지 않고 경로도 짧아서 안전해요.

    설치 전에 Claude나 ChatGPT 앱을 켜뒀다면 완전히 껐다가 다시 켜세요. 작업 표시줄 오른쪽 아래의 앱 아이콘을 우클릭해서 "종료"를 누르면 됩니다. 안 그러면 AI가 방금 설치한 도구를 못 찾아요.

    AI에게 설치 확인 맡기기

    폴더를 연 AI 앱 채팅창에 아래 문장을 붙여넣고 보내세요. AI가 직접 확인해서 표로 알려줍니다.

    Git, Node.js, Python, uv, GitHub CLI, Vercel CLI, Supabase CLI가 잘 설치됐는지 확인해줘. GitHub, Vercel, Supabase는 로그인됐는지도 봐줘. 결과는 표로 보여주고, 문제가 있으면 쉬운 말로 고치는 법을 알려줘.

    왜 AI에게 확인하나요? PowerShell에서는 잘 되는데 AI 앱만 도구를 못 찾는 경우가 있어요. AI가 직접 확인해서 전부 문제없다고 하면 수업 준비가 정말 끝난 거예요.

    AI가 "실행해도 될까요?"라고 물으면 허용(Allow 또는 Approve)을 누르세요. 문제가 있다고 나오면 AI가 알려주는 대로 따라 하거나, 그 화면을 선생님께 보여주세요.

막혔을 때

"이 시스템에서 스크립트를 실행할 수 없으므로..." 라고 나와요 (Windows)

설치 명령어를 한 번 더 실행하세요. 설치 스크립트가 이 설정을 풀어줍니다.

그래도 계속 나오면 학교나 회사가 관리하는 PC일 가능성이 높아요. 이 경우는 PC 관리자만 풀 수 있으니 선생님께 알려주세요.

"명령을 찾을 수 없습니다" / "인식되지 않습니다" 라고 나와요

창을 완전히 닫고 새로 연 다음 다시 해보세요. 그래도 안 되면 컴퓨터를 재시작하세요.

AI 앱이 "node가 없다", "gh가 없다"고 해요

설치하기 전에 앱을 켜뒀다면 새로 설치된 도구를 못 봅니다. 앱을 완전히 종료하고 다시 켜세요.

Windows는 작업 표시줄 오른쪽 아래 앱 아이콘을 우클릭해서 "종료", Mac은 앱을 앞에 띄우고 ⌘ + Q.

python을 치면 Microsoft Store가 열려요 (Windows)

설정 → 앱 → 고급 앱 설정 → 앱 실행 별칭에서 python.exe, python3.exe를 끄고 설치 명령어를 다시 실행하세요.

Mac에서 "관리자 계정이 아닙니다" 라고 나와요

설치에는 Mac 관리자 계정이 필요합니다. 시스템 설정 → 사용자 및 그룹에서 내 계정이 "관리자"인지 확인하세요. 학교나 회사 Mac이라면 관리자에게 부탁해야 합니다.
